## Requirements

- Python 3.x
- The WHOIS programs require `python-whois`
- DNS program 05 uses `dig` when available and falls back to `nslookup`

Install the WHOIS package:

```bash
pip install python-whois
```

## How to Run

Clone the repository:

```bash
git clone https://github.com/vasuparmar150392/MSc-CS-1-Python-Program-Practical.git
cd MSc-CS-1-Python-Program-Practical
```

Run a program:

```bash
python "Unit 5 Practical/01.Python Program to Perform WHOIS Lookup.py"
```
